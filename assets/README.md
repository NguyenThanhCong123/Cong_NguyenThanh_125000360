# THƯ MỤC TÀI NGUYÊN (ASSETS)

Thư mục này chứa các tài nguyên phục vụ cho website GymStore:
- **Logo chính thức (`logo.png`):** Logo nhận diện thương hiệu hình tròn màu đỏ GymStore (Sport Nutrition Supplement - Since 2011), dùng cho Favicon tab trình duyệt và hiển thị tại Header & Footer website.
- **Hình ảnh:** Được tối ưu hóa tải trực tuyến qua CDN Unsplash chất lượng cao (HD Fitness & Nutrition photography) nhằm giảm tải dung lượng khi nộp bài và đảm bảo GitHub Pages tải nhanh nhất.
- **Biểu tượng (Icons):** Tích hợp qua CDN Font Awesome 6.5.1 chính thức.
- **Hiệu ứng chuyển động (Libraries):** Tích hợp qua CDN Animate.css v4.1.1 và AOS (Animate On Scroll) v2.3.4.
- **Fonts:** Google Fonts (Montserrat & Plus Jakarta Sans).
